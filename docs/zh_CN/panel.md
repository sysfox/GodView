# 面板

[← 文档首页](README.md)

控制台是一个编译到插件 jar 中的 Vue 应用程序。它不从互联网加载任何内容——没有 CDN、没有网络字体、没有分析工具——并且在仅允许同源资源的 Content-Security-Policy 下提供服务。它可以在断网环境下运行。

## tick 条

头部那一排竖条是需要了解的唯一内容。

```
▏▎▏▏▎▏▏▎▏▏▏▎▏▏▎▏▏▏▎▏▏▎█▏▏▎▏▏▏▎▏▏▎▏▏▏
                      ↑
                 一个 tick 耗时 340 ms
```

**每条竖线代表一个 tick，高度表示耗时。** 横线标记 50 ms——一个 tick 的完整预算。线以下表示服务器跟得上，以上表示服务器跟不上。

tick 条故意设计为单色，直到出现问题为止。健康的服务器绘制出均匀的灰色梳子，融入界面背景；超过 75 ms 的条变为琥珀色，超过 120 ms 的条变为红色。由于页面上没有其他彩色元素，一根红色条就是屏幕上唯一有颜色的东西——这让你一眼就能发现，而不是又一个被习惯性忽略的闪烁指示器。

它在每个视图的头部都出现，所以你可以在阅读日志的同时看到 tick 超时的瞬间。

## 实时

仪表板。它不是以仪表盘开始的，而是一句话：

> **吃力**
> 12.40 TPS，最近十秒最差 tick 812 ms。**ShopGUI** 在 40 秒前卡住服务器 812 ms。

在凌晨两点，这句话比页面上的任何数字都更有价值，因此结论放在最前面，其他所有内容都为其提供支撑。

下方：完整尺寸的 tick 条、四个关键统计数据、一小时的 TPS 和堆内存趋势、按世界划分的实体和区块数量（含三种最常见的实体类型）、以及最近的卡顿表格。

**阅读卡顿表格。** "归因"通过从最内层帧向外遍历捕获的栈，并命名它遇到的第一个插件来判定。一个调用慢速服务端方法的插件仍然会承担责任——这是诚实的答案，因为它是选择发起该调用的一方。`Minecraft` 表示栈中未出现任何插件：这是原版的工作，通常是实体 tick 或区块生成。

需要完整的调用树，请安装 [spark](integrations.md#spark)。GodView 告诉你*某个* tick 耗时 800 ms 以及哪个插件的帧在最顶层；spark 告诉你数千个样本中的时间分布情况。

## 玩家

所有在线玩家，每五秒刷新一次，显示延迟、生命值、游戏模式、位置和游戏时间。Operator 还可以看到地址并进行踢出和封禁操作。

两个操作都需要输入理由，无论成功与否都会被记录到审计日志。

## 控制台

真实的服务端控制台——根 Log4j 输出，而不仅仅是 Bukkit 的日志，因此 Netty、世界加载器和其他插件的原始日志都会出现。

支持级别过滤，以及一个仅在滚动到底部时才会自动滚动的跟随开关。有人向上滚动阅读栈跟踪是有意为之的操作。

Operator 有一个命令输入框。输出**不会**内联返回——它会出现在上方的日志中，带有时间戳。捕获输出意味着需要给插件提供一个代理的 `CommandSender`，而将 sender 转换为具体类型的插件会以你无法诊断的方式崩溃。

Viewer 只能看到警告和错误。INFO 输出通常包含玩家加入时的 IP 地址。

## 事件

服务器记录的所有事件：加入、退出、聊天、命令、死亡、踢出、控制台错误、世界加载。可按类型、玩家或自由文本过滤。

此处显示哪些事件由 [`capture:`](configuration.md#capture) 控制。方块事件默认关闭，因为它们每秒触发数千次——需要方块历史请安装 CoreProtect。

未过滤的列表会实时刷新；已过滤的列表不会，因为在阅读结果时重新执行搜索比显示稍过时的结果更糟糕。

## 地图

世界的俯视图，拖拽平移，滚轮缩放，玩家显示在地图上。

瓦片生成有严格的每 tick 预算，因此一个之前没访问过的瓦片需要一两秒才能填充完毕，而不是立即显示。这是防止地图成为拖慢服务器的元凶所做的取舍。详见[地图](map.md)。

## 告警

每条规则及其类型、级别、触发次数和冷却状态；每个渠道及其可用性和原因；以及触发历史。

管理员可以在每条规则上执行**发送测试**，通过该规则的渠道推送一条模拟告警。它会绕过静默时段——这是手动发送的，某人现在就想知道它能否到达。

历史记录显示每个渠道是否接受了每条告警。一条触发但未送达任何人的告警与一条从未触发的告警是不同的——前者只是配置错误的 webhook。

## 诊断

GodView 自身的运行状态：JVM 和主机的详细信息、其自身的请求和流计数器、存储行数和队列深度、GC 统计信息、哪些集成已连接，以及完整的插件列表。

需要关注的两个数字：

- **存储排队/丢弃。** 丢弃应始终为零。非零值意味着磁盘跟不上，数据行被丢弃而非拖慢服务器。
- **流帧丢弃。** 速度太慢无法跟上的客户端会丢失帧，而不会对 tick 循环产生背压。

## 会话和退出

会话持续两小时，在活跃时自动续期，因此面板不会在事故处理过程中将你登出。退出登录会立即在服务端结束会话。

在面板中更改自己的密码需要输入当前密码——会话已经证明了你身份，但这意味着有人走到未锁屏的浏览器前无法悄无声息地接管账号。更改密码同时会结束该账号的所有其他会话。
