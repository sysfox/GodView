## 关于本文档的写作风格

每一页都试图说明**为什么**，而不仅仅是**是什么**。一个写着"控制采样间隔"的配置项告诉你的无非是从名称中能猜到的东西；而写着"这是低端服务器上地图的主要开销，设为 1–2 即可"则告诉你怎么做决策。

文中涉及真实权衡的地方——确实有几处——会明确说明取舍，而不是隐藏在默认值背后。
